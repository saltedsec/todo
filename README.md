# 스터디 To-Do 리스트

시험 일정과 과제를 간편하게 정리하고, 완료 현황과 마감일을 한눈에 확인할 수 있는 반응형 할 일 관리 웹 앱입니다. 브라우저의 `localStorage`를 사용하므로 별도의 회원가입이나 서버 없이 사용할 수 있습니다.

## 주요 기능

- 할 일, 카테고리, 마감일, 우선순위를 입력해 새 항목 등록
- 체크박스로 완료 상태를 변경하고, 완료 항목은 취소선과 회색 스타일로 구분
- 삭제 전 확인 팝업 표시
- 전체 완료율을 진행 막대와 색상으로 표시
- 미완료 항목은 마감일까지 3일 이하일 때 임박 상태를 표시하고, 오늘 마감과 기한 초과를 구분
- 전체·오늘 등록·완료 항목 필터
- 빈 입력 방지, 긴 문장 줄바꿈, 입력 내용을 텍스트로 표시해 HTML이 실행되지 않도록 처리
- `localStorage`에 할 일 목록을 저장해 새로고침 후에도 유지
- 좁은 화면에서도 사용할 수 있는 반응형 레이아웃

## 기술 및 구현

- HTML, CSS, Vanilla JavaScript
- Tailwind CSS CDN 및 `style.css`의 사용자 정의 스타일
- `localStorage`에 `todos` 키로 JSON 데이터 저장
- 프레임워크 설치나 빌드 과정 없이 실행

요구사항은 [PRD.md](./PRD.md)에 정리하고, 동작은 [script.js](./script.js), 화면 구조는 [index.html](./index.html), 사용자 정의 디자인과 반응형 스타일은 [style.css](./style.css)에 구현했습니다. 이후 삭제 확인, 완료 항목의 일관된 표시, 진행률 색상, 마감 임박 안내를 보완했습니다.

### Bootstrap과 Tailwind

현재 저장소에는 Tailwind CSS CDN을 사용한 구현이 포함되어 있습니다. Bootstrap으로 만든 별도 버전은 이 저장소에 포함되어 있지 않아 실제 두 버전의 화면을 비교했다고 기술하지 않습니다.

일반적으로 Bootstrap은 미리 정의된 컴포넌트 클래스(예: 버튼, 카드)를 조합하는 방식이고, Tailwind는 여백·색상·레이아웃 등의 유틸리티 클래스를 HTML에 조합하는 방식입니다. 이 프로젝트에서는 Tailwind의 반응형 유틸리티 클래스로 기본 레이아웃을 구성하고, 투두 카드와 진행률 색상 등 세부 디자인은 `style.css`에서 보완했습니다.

## 실행 방법

저장소를 내려받거나 복제한 뒤 프로젝트 폴더에서 로컬 웹 서버를 실행합니다.

```bash
git clone https://github.com/saltedsec/todo.git
cd todo
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다. Tailwind CSS를 CDN에서 불러오므로 화면을 열 때 인터넷 연결이 필요합니다.

### GitHub Pages 배포

GitHub 저장소의 **Settings → Pages**에서 배포할 브랜치와 폴더를 지정하면 정적 사이트로 배포할 수 있습니다. 저장소 이름이 `todo`인 경우 기본 주소 형식은 <https://saltedsec.github.io/todo/>입니다. Pages가 활성화되어 있지 않으면 해당 주소에서 사이트를 볼 수 없습니다.

## 커스터마이징한 부분

- 완료율 구간에 따라 진행 막대와 퍼센트를 빨강·주황·초록으로 표시하고, 할 일이 없을 때는 중립 색상을 적용했습니다.
- 완료 항목은 내용 취소선뿐 아니라 카드와 관련 태그도 회색 톤으로 통일했습니다.
- 마감일까지 3일 이하인 미완료 항목에 남은 날짜를 표시하고, 오늘 마감과 기한 초과 상태는 별도 색상으로 구분했습니다.
- 삭제 확인 팝업을 추가해 실수로 항목을 제거하는 일을 줄였습니다.
- 사용자 입력은 `textContent`로 출력하고, 잘못된 저장 데이터와 저장 실패에는 안내를 표시합니다.
